### Faire le commit dans CS code:
- Aller dans VS code puis cliquer sur control puis parametre si possible
- Aller dans la barre des tache en haut à gauche de l'écran puis selectionner "Terminal" puis "New Terminal"
- Tapper exactement dans le terminal : *git config --global user.email"_email d'ouverture sur github_"* puis valider
- Tapper exactement dans le terminal : *git config --global user.name"_username sur github_"*
- Le processus est à faire une seul fois dans le terminal
- Puis aller dans l'espace de saisi de texte et tapper le message "initialisation du dépôt"
- Appuier sur le bouttum commit pour puis sur le bouttum "always" du massage qui s'affiche sur l'écran
- Aller dans le groupe Github et continuer le dépôt

### Historique des FabLabs

- Les fablabs trouvent leur origine a partir du Cours populaire "How to Make(Almost) Anything" du professeur Neil Gershenfeld en 1990. Le réseau a ensuite évolué mondialement avec la Fab Fondation pour structurer, promouvoir  et accompagner l'expension du réseaumondiale des laboratoire. Au TOGO, ZoeLab fut le premier espace FabLab reconnu moondialement. Et le réseau est entrain de s'étendre, en 2026 sur le territoire, à travers le 101 FabManagers qui seron déployé dans les FabLab éducatif et les Centre Régionaux d'Inovations Technologiques (CRIT).
